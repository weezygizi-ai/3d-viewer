# 3D Viewer

Kostenlose Web-App (PWA) zum Ansehen von **GLB-, GLTF- und FBX-Modellen** – optimiert fürs iPhone.

**App öffnen:** https://weezygizi-ai.github.io/3d-viewer/

- Texturen, Rigs/Skelette, Morph-Targets und alle Animationen werden angezeigt
- Animationen auswählen, abspielen/pausieren, Geschwindigkeit, Zeitleiste
- Drehen, Zoomen (Pinch) und Verschieben mit den Fingern
- Gitternetz-, Skelett-, Boden- und Hell/Dunkel-Ansicht, Modell-Infos
- Draco-, Meshopt- und KTX2-komprimierte GLB-Dateien
- Dateien bleiben auf dem Gerät, nichts wird hochgeladen
- Funktioniert offline

**Auf den Homescreen legen:** In Safari öffnen → Teilen → „Zum Home-Bildschirm“.

Basiert auf [three.js](https://threejs.org) r170 (MIT-Lizenz, liegt unter `vendor/three`).
